# Scientific Grounding

## Evidence Record Structure
Each piece of evidence in the system is structured to include:
- Claim / Finding
- Context (e.g., biome, soil type)
- Source Citation
- Confidence Level (High, Medium, Low)
- Quantitative Data (if available)

## How Fabricated Claims are Avoided
The system operates on a strict "retrieval-first" paradigm. The LLM prompt explicitly instructs the model to refuse to answer or generate recommendations if no relevant evidence is found in the vector store. Hallucination checks are performed by ensuring all output claims trace back to a retrieved chunk ID.

## Confidence Level Determination
Confidence levels are assigned during ingestion based on the source type:
- **High**: Peer-reviewed meta-analyses, primary research papers from reputable journals.
- **Medium**: NGO reports, agricultural extension documentation.
- **Low**: Anecdotal reports, non-reviewed articles.

## Distinguishing Evidence-Backed vs Qualitative Claims
The UI visually distinguishes claims. Evidence-backed claims display citation links and confidence badges. Qualitative or general claims generated by the LLM (e.g., conversational filler or basic explanations) are presented without badges.

## Environmental Relationship Graph
The system uses a graph to understand interactions. For example, `[Cover Crops] -> (increases) -> [Soil Organic Carbon] -> (improves) -> [Water Retention]`. This prevents the system from suggesting conflicting interventions.

## Multi-Metric Reasoning Approach
Before generating recommendations, the engine evaluates the user's profile across all metrics. If an intervention improves biodiversity but severely depletes water in a drought-prone area, the reasoning engine flags this trade-off, ensuring holistic recommendations.
